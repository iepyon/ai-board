# 手順書の版

ループの手順書（`.claude/` のスキル・サブエージェント・許可ルール）の変更履歴。新しい版を上に足す。
`ai-board loop start` が先頭の `## v<番号>` の版を 1 手の記録に残す（`status --json` の `cards[].loopSteps[].harness`）。版ごとの成績を比べるのに使う。

版を上げるのは、ループの振る舞いが変わる変更のとき。手順書を変える計画では、AI が「版を上げる」タスクを提案し、上げるかは人が計画レビューで決める。
言い回しの直しなど振る舞いの変わらない変更では上げない。

## v5 — 2026-11-06

人の判断の種別「否決」を「差し戻し」と呼び替える（`send-back-wording`）。

- `## レビュー` の種別と `status --json` の `kind` の値が `差し戻し` になった。計画レビューの判断のラベルは「差し戻す」になった。CLI のサブコマンド（`decide reject`）とログのファイル名（`reject`）は変わらない
- `board-decide` は「否決して」と頼まれても、差し戻しの依頼として受ける
- `board-loop`（`SKILL.md`・`plan.md`・`rules.md`）と `adr` の「否決」を差し戻しに直した。`revise-plan` の回答の出どころは `plan 差し戻し` と書く

## v4 — 2026-11-06

計画で、範囲の線引きも人に判断してほしいことに挙げる（`plan-scope-decisions`）。

- `plan.md` の「人に聞くこと」の例に、範囲の線引き（入れるか外すかで、成果物の範囲か CLI の出力・振る舞いが変わるもの）を足した
- `### Non-Goals` と `### 退けた代案` のうち範囲の線引きに当たるものは、既定を添えて `## 人に判断してほしいこと` にも挙げ、元の行に「（人に判断してほしいこと）」と添える
- 節の説明に `### Non-Goals` の行を足した
- 提出の前の確かめに、Non-Goals・退けた代案・仮定を毎回読み直し、範囲の線引きがすべて人に判断してほしいことにあるかを確かめることを足した。`### 仮定` に書いた範囲の線引きも挙げる
- 既定と違う答えは plan 否決の理由で返してもらい、plan 承認は回答の無い項目をすべて既定のまま進めると読む。`board-decide` は、違う答えを添えた承認の依頼を、否決で返すか既定のまま承認するかを聞いてから書く
- `revise-plan` でも、直した計画で探索メモの表と範囲の線引きの読み直しを行う

## v3 — 2026-11-06

`status --html` のダッシュボードをいったん外した（ADR 0017）。

- `board-dashboard` のスキルを消した。「ボードを見せて」は、周とは別に `ai-board status` の出力を見せるだけになった
- `board-reviewer` に渡さないものの例を、ダッシュボードで読んだ中身から `status` で読んだ中身に直した

## v2 — 2026-11-05

ボードの画面とサーバをいったん外した（ADR 0017）。

- 手順書から、画面のボタン・サーバ・`server.json`・人の API（`/api/...`）の記述を消した。人の判断の入口は `ai-board decide`（チャットからは `board-decide`）だけになった
- `board-loop` の共通の決まりの「使わないもの」は、`board-decide` のスキルと `ai-board decide` の 2 つになった
- 計画と締めの段の「人が目で見て確かめるもの」の例を、画面の見た目から一般の言い方に直した

## v1 — 2026-11-05

この版から記録を始めた。これより前の 1 手の記録は「版なし」として並ぶ。

- ループは本筋のセッション 1 つで回し、AI レビューの段だけを `board-reviewer` のサブエージェントに切り分ける（ADR 0011）
- 人の判断ゲートは 計画レビュー と PR中 の 2 つ。動作確認の結果は締めの段で AI が PR の本文に書く（ADR 0005）
- 計画は冒頭に `## 人に判断してほしいこと`、設計に `### 仮定` と `### 退けた代案`、設計の後に `## 探索メモとの対応` を置く
- PR中 で人の指摘に AI が応える `fix-pr` の手がある（ADR 0016）
- 人がチャットで頼んだ判断を `board-decide` で書いた後、AI の番ができたら同じセッションで 1 周を続ける（ADR 0013）
