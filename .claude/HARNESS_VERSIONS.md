# 手順書の版

ループの手順書（`.claude/` のスキル・サブエージェント・許可ルール）の変更履歴。新しい版を上に足す。
`ai-board loop start` が先頭の `## v<番号>` の版を 1 手の記録に残し、ダッシュボードの「振り返り」が版ごとの成績を並べる。

版を上げるのは、ループの振る舞いが変わる変更のとき。手順書を変える計画では、AI が「版を上げる」タスクを提案し、上げるかは人が計画レビューで決める。
言い回しの直しなど振る舞いの変わらない変更では上げない。

## v1 — 2026-11-05

この版から記録を始めた。これより前の 1 手の記録は「版なし」として並ぶ。

- ループは本筋のセッション 1 つで回し、AI レビューの段だけを `board-reviewer` のサブエージェントに切り分ける（ADR 0011）
- 人の判断ゲートは 計画レビュー と PR中 の 2 つ。動作確認の結果は締めの段で AI が PR の本文に書く（ADR 0005）
- 計画は冒頭に `## 人に判断してほしいこと`、設計に `### 仮定` と `### 退けた代案`、設計の後に `## 探索メモとの対応` を置く
- PR中 で人の指摘に AI が応える `fix-pr` の手がある（ADR 0016）
- 人がチャットで頼んだ判断を `board-decide` で書いた後、AI の番ができたら同じセッションで 1 周を続ける（ADR 0013）
