## アイデア

「ボードを見せて」で出すページ（`board-view`）で、カードのタイトルを押すと PR が開くようにする。

- **タイトルをリンクにする。** PR のあるカード（`prUrl` がある）は、タイトルそのものを PR へのリンクにする。新しいタブで開き、`rel="noopener noreferrer"` を付ける（今の「PR を開く」と同じ）
- **PR の無いカード。** タイトルは今までどおりの文字にする
- **メタの行の「PR を開く」。** タイトルがリンクになったら外すか、残すかを決める
- **直すのはひな形だけ。** `.claude/skills/board-view/template.html` の描画の JS と CSS を直す。`render.mjs` が流し込むデータの形と、`status --json --active` は変えない

## 背景

2026-11-11、PR #103 のブランチで「ボードを見せて」のページを動かして確かめた。
PR へのリンク（「PR を開く」）は、ID やステージの札と同じ小さな文字の行に紛れていて、スマホでは押しにくい。
判断待ちのカードを見つけたあと次にするのは PR を開くことなので、いちばん大きな文字であるタイトルを押せば開けるほうが自然である。
このページは PR #103 で入るので、このカードはそのマージの後に進める。

## 論点

- **リンクの見た目。** 下線を常に出すか、ホバーだけにするか。タイトルの太字の見た目をどこまで残すか
