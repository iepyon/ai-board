## アイデア

ループが 1 手ごとの記録（どのカードに、どの手を、いつ始めていつ終えたか、結果）を履歴として残し、ボードがそれを読む。

- **履歴を残す。** 監視役が作業者に 1 手を渡すときに開始を、報告を受けたときに終了と結果（進んだ / 止まった / 保留を書いた）を書く。
  置き場所は計画で決める（`.ai-board/loop.json` を履歴の形にするか、DB の別の表にして `ai-board` の CLI から書くか）
- **今どのカードを触っているか。** 終わっていない最新の 1 手がそれに当たる。トップバーに出し、対象のカードに稼働バッジを付ける
- **時間の内訳に使う。** `stage-timeline` の AI の区間を、「ループが拾うまでの待ち」（区間の始まり → 1 手の開始）と「作業者が動いていた時間」（1 手の開始 → 終了）に分ける。グラフは `bottleneck-chart` で使う
- **カードには持たせない。** ループの状態はカードの属性ではないため。ステージの導出にも使わない

## 背景

ボードはカードのステージを示すが、AI が今どのカードを触っているかは一切示さない。
`/loop` で間隔運転していると、ループが動いているのか、止まっているのか、どのカードで詰まっているのかを
画面から知る手段が無い。確かめるにはターミナルを覗くしかない。

ボードを開けばループの様子も分かるようにしたい。ループを任せきりにするには、
止まったことにすぐ気づけることが前提になる。

## 論点

- **作業記録へのリンク。** Mastra Factory はカードから Session（エージェントの会話の記録）を開ける。
  ai-board でも、ループが `loop.json` に Claude Code のセッション ID を書き、ボードからその記録
  （`~/.claude/projects/` のログ）を辿れるようにするか。カードの属性にはしない方針と両立させる
- **ループを並べて動かす。** `pickNextAction` はボードの状態だけで 1 枚を決めるので、
  `/loop` を 3 つ並べると 3 つとも同じカードの同じ手を選ぶ。`plan` はブランチの重複で片方が止まるが、
  `implement` は同じワークツリーで同じタスクを同時に書き始める。並べるには、作業を始めたループが
  「このカードを触っている」と宣言し、`pickNextAction` が宣言済みのカードを飛ばす必要がある。
  この宣言は、本カードで見せたい「今どのカードを触っているか」と同じ情報である。
  `loop.json` が 1 ループ 1 件の形のままだと足りないので、ループごとの識別子を持つ複数件の形にするか。
  宣言の書き込みと読み取りの間で 2 つのループが同じカードを取らないよう、取得を原子的にできるか
  （ファイルなら排他作成、DB なら 1 文の更新）。落ちたループの宣言を時刻で失効させるか

## 探索メモ

2026-10-31 の対話で、ボードを「AI 駆動開発のボトルネックを意識できるもの」に発展させる方針になり、このカードを今の稼働の表示から 1 手ごとの履歴へ広げた。
AI の区間を待ちと作業に分けることにしたのは、「AI が遅い」のうち、ループの間隔や並列度が原因か、作業そのものが原因かを見分けるためである。

2026-11-02 の対話で、人が論点に次のとおり答えた。計画はこれを前提に書く。

- **履歴はデータ用ブランチに置く。** `ai-board/data` に履歴のファイルを置き、CLI が書くたびにコミットして push する。クラウドのセッションが片付けられても残り、別の端末のボードからも見えるようにするため。1 手ごとにコミットが増えるのは受け入れる
- **書くのは監視役で、CLI から書く。** 監視役はサブエージェントに渡すときに開始を、完了の通知を受けたときに終了・結果・トークン・時間を書く。トークンは完了の通知（`usage` の `subagent_tokens` / `duration_ms`）にしか出ないので、監視役しか書けない。
  書き込み境界に「監視役は履歴だけを書ける（カードには書かない）」を足し、CLI の入口もカードを書けない形にする
- **並べて回すための宣言は別のカードにする。** このカードは「見る」だけにする。ただし履歴の形は、後で宣言に使えるよう、ループごとの識別子を持たせておく。原子的な取得や失効は入れない
- **見せるものは 3 つとも入れる。**
  - 今触っているカード（トップバーと、対象のカードの稼働バッジ。`status --html` の出力にも出す）
  - 1 手ごとの時間とトークン（カードの詳細に、手の一覧として出す）
  - `stage-timeline` の AI の区間を「ループが拾うまでの待ち」と「作業者が動いていた時間」に分ける
