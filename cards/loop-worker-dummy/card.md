## アイデア

**動作確認用のダミーのカード。** 計画を書いて Draft の PR を出し、`plan 提出` を書いたところで止まればよい。
計画のタスクは「README の末尾に 1 行足す」程度の小さなもの 1 つだけにする。承認はせず、確認が済んだら人が中止して PR を閉じる。

## 背景

PR #35（`loop-fresh-context`）で、`/board-loop` を回すセッションを監視役にし、1 手ごとの作業を
まっさらな文脈の作業者（`.claude/agents/board-worker.md`）に渡す形にした。
`ListAgents` による作業中の判定と作業者の型の解決は単体で確かめたが、実際のカードで 1 周回したことはまだ無い。

確かめたいのは次の 2 つである。

- 作業者がカードのワークツリーを切り、計画をコミットして Draft の PR を出し、`plan 提出` を書いて数行の報告を返すこと
- 作業者が動いている間に `/board-loop` をもう一度呼ぶと、「作業中」とだけ伝えて何も渡さないこと
