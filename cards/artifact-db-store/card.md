## アイデア

カードの正本を、git のデータ用ブランチ `ai-board/data` から Claude の Artifact の DB へ移す。データ用ブランチはやめる。
置き場所はあとから SQLite に差し替えられるよう、1 つの口に閉じる。
fork や研修で最初に入れるアイデアカードは、`main` に置いた固定の seed ファイルから起票する。

## 背景

- データ用ブランチ（ADR 0010）は、orphan のブランチ・データのワークツリー・ロックと push の楽観ロック・`AI_BOARD_DATA` での試し・`init` での作成・`card export` での持ち出しなど、特殊なやり方が多く、fork や研修の準備が手間になっている
- 普段の開発は PC とスマホの両方で行い、スマホからもカードを直したい。PC は閉じたままでよい
- オフラインの研修（手元モード）は要らなくなった

## 論点

- node の CLI は Artifact の DB に直接届かない。DB を読み書きできるのは、公開したページと、Claude の `ArtifactData` のツールだけ
- AI と人の書き込みの境界（`ai-board card` の構造で守っていたもの）を、DB の側では表せない（DB の権限は人ごとで、Claude は人の権限で書く）
- 今のデータ用ブランチのカード・判断・並び順を、どう DB へ移すか

## 探索メモ

2026-11-17 に人とチャットで決めたこと。

- 困っているのは、fork や研修の準備と、データ用ブランチという特殊な持ち方。普段の開発は PC とスマホで行い、スマホでも直したい
- スマホで触るとき、PC は閉じたままにしたい。オフラインの研修は要らない
- データ用ブランチはやめて、正本は Artifact の DB にする。あとから SQLite に切り替えられるようにする。データ用ブランチは特殊なやり方すぎたので採らない
- 最初のアイデアカードは、固定の seed ファイルでよい
