カードの無い計画の帯を既定で閉じた <details> にした（PR #40、Draft のまま）。動かして確かめてほしい。

手順（ワークツリー ~/src/ai-board/.claude/worktrees/8 で）
1. npm run build
2. export AI_BOARD_DB="$(mktemp -d)/board.db" の後に node dist/cli.js --root . --port 5683 --no-open で起動し、http://127.0.0.1:5683 を開く
3. ページの末尾で次を見る
   - 「▸ カードの無い計画 N 件」と説明の 1 文が出て、計画の ID の一覧は見えない
   - 見出しを押すと ▾ に変わり ID の一覧が出る。もう一度押すと閉じる
   - 開いたまま、同じ AI_BOARD_DB を指した別の端末で node dist/cli.js card create --title 試し --id try-card --root . < /dev/null を実行し、ボードが読み直されても帯が開いたまま残る
   - ライトとダークの両方で、帯の色と印が読める
4. 「GitHub に接続できません」の帯を出せるなら、畳まれずに今のまま出る（出せなければ見送ってよい）
5. サーバを止める

自分で動かした結果
- 空の DB で起動し、GET /api/board の orphanPlans が 18 件（ワークツリーの plans/ と plans/archive/ の計画すべて）返ること、forge が connected であることを確かめた
- 配信された CSS / JS に warn-fold の規則（summary の横並び、既定の三角を消す規則）と <details> が入っていることを確かめた
- card create でカードを足すと /api/events に board-changed が流れ、/api/board のカードが 1 枚になることを確かめた

計画の手順から変わった点
- card create はタイトル「試し」から ID を作れず失敗するので、--id try-card を足した
- 今のワークツリーでは件数は 8 件ではなく 18 件（計画 8 自身とその後 archive された計画を含む）

確かめられなかった部分
- 画面の見た目（閉じたときに 1 行に収まるか、▸ / ▾ の切り替え、開いた状態が読み直し後も残るか、ライト / ダークの色）はブラウザを動かしていないので見ていない
- 「GitHub に接続できません」の帯は、接続できる環境だったので出していない

AI レビューの見送った指摘 5 件は PR の本文の「見送った AI レビューの指摘」に写した（▸ / ▾ の印が警告色になり details.fold の灰色と揃わない点など）。人に判断してほしいことの指摘は無い。
