## アイデア

ループの 1 手の記録（`loop/`）に手順書の版を付け、版ごとの成績をボードで見られるようにする。
自動化をどこまで任せるか（例: 計画レビューを飛ばしてよいか）を、人が数字を見て進めたり戻したりできるようにする。

- **手順書の版。** 1 手の記録に、その時の `.claude/`（スキル・サブエージェント）のコミットを残す
- **成績。** 版ごとに、否決率、差し戻しの回数、人を待った時間、1 手のトークン数と時間を集計する
- **見せ方。** ボードの画面と `status --html` のダッシュボードで、工程ごとの時間（ボトルネック）と版ごとの成績をグラフにする
- **進める・戻すの目安。** 段階を進める条件と戻す条件を、人が README か設定に書いておき、成績と並べて見せる。段階を変えるのは人で、AI は変えない（skipGates を AI が足さない決まりは今のまま）

## 背景

これまでのマージ済み 29 枚のうち約半分は、ループ自身（手順書）を変えるカードだった。手順書を変えて良くなったかは、人の印象でしか分かっていない。

Mastra Factory は、判定の記録ごとに `configVersion`（どの設定の下での判定か）を残す。
研修の設計では、自動化を段階 0（全部人）から順に開け、段階ごとに「次へ進む条件」と「1 段戻す条件」を先に決めておくことを教える。

## 論点

- **bottleneck-chart・status-html-catchup との関係。** 工程ごとの時間のグラフと、ダッシュボードで区間の時間とループの手を読むアイデアは、この中に含める
- **版の粒度。** `.claude/` 全体のコミットにするか、手ごとに使ったスキル・エージェントのファイルだけのハッシュにするか
- **記録の形。** `loop/` の記録の形を変えるので、データ用ブランチの形の版（`ai-board-data.yaml`）を上げるか。古い記録は版なしとして扱う
- **件数の少なさ。** 版ごとのカードの枚数は少ない。比べ方（直近 N 手、版をまたいだ移動平均など）をどうするか
- **回帰の確かめ。** 決まった題材のカードで 1 周を回し、成績と振る舞い（Draft の PR が出た、提出だけを書いた等）を確かめる仕組みを、この上に載せるか

## 探索メモ

2026-11-03 のアイデアの整理で、`loop-retry-limit`（AI の手が同じところで止まり続けたら上限で人に回す）をこのカードにまとめた。
回数は、このカードの成績と同じループの 1 手の記録（`loop/`）から数える。何を数えるか・上限の置き場所・数えなおしの合図は `loop-retry-limit` の本文の論点を引き継ぐ。
メトリクスとチャートは研修で改良したいので、このカードと `bottleneck-chart` は残す（人が 2026-11-03 に決めた）。

2026-11-05 に人と詰めたこと（問い・答え）。

- 調べて分かった前提: ダッシュボード（`status --html`）の「振り返り」に、工程ごとの滞在時間とボトルネック、否決の数、人の区間の割合、手の種類ごとの件数・平均時間・平均トークンが既にある（`src/shared/board-metrics.ts`）。足りないのは版で分けることと、版の記録。
  1 手の記録は 11/2 から 76 件、同じ期間の `.claude/` へのコミットは 53 回。トークンが入っているのは 76 件中 20 件（どれも `board-reviewer` の段）
- どこで作るか？ → このリポジトリで一旦作る。研修用には後で削る
- 版の単位は？ → 人が付ける版番号。コミット単位では 1 版 1〜2 件になり比べられない
- 版番号の置き場所と上げ方は？ → 変更履歴のファイル（例: `.claude/HARNESS_VERSIONS.md`）に「版・日付・何を変えたか」を並べ、先頭の版を今の版と読む。手順書を変える計画では AI が「版を上げる」タスクを提案し、人が計画レビューで決める
- 版ごとに比べるものは？ → 否決率、人を待った時間、時間とトークン、手の止まりとやり直しのすべて
- トークンは？ → 本筋のセッションの手でも、Claude Code の会話の記録（`~/.claude/projects` の JSONL の usage）を手の開始から終了まで足して埋める。記録の形が変われば取れなくなる（取れなければ今どおり「—」）
- 段階と進める・戻す条件は？ → 作らない。版ごとの数字を並べて見せるだけで、判断は人が数字を見て行う
- `loop-retry-limit` は？ → このカードでは、同じカード・同じ手の「止まった」が続いている回数を数えて見せるだけ。上限で人に回すのは `loop-retry-limit` のカードに残す
- 版の無いこれまでの記録は？ → 「版なし」として 1 つの列にまとめ、最初の版と比べられるようにする
