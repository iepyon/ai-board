## アイデア

「ボードを見せて」と頼むと、アイデアの一覧・AI 作業中・判断待ちの 3 つの区画を並べたボードを、Artifact の 1 枚の HTML のページで出す。

- **中身は `ai-board status --json --active` をそのまま使う。** 手元のデータ用ブランチを読み、PR の状態だけを `status` と同じく `gh` で引く。判断待ちは `waiting`（出せる判断つき）、AI 作業中は `working`、アイデアの一覧は `ideas`（rank の順、区切り線つき）、ループの様子は `loop`、GitHub の接続は `forge` を描く。ページの側でステージや区画を導出しない
- **データはページに埋め込む。** Artifact の DB（`db` の能力）・コネクタ（`mcp`）・ページ自身の保存（`artifact`）は使わない。ページは頼んだ時点の写しで、新しくするには頼み直して同じ URL へ出し直す
- **見た目は固定のひな形で決める。** HTML のひな形と、JSON を流し込む決まった手順をリポジトリに置き、Claude が毎回 HTML を書かない（頼むたびに見た目がぶれないように）
- **見渡すことだけに絞る。** グラフ・集計・ログ・更新ボタンは付けない
- **判断はページから書かない。** 判断待ちのカードには出せる判断を並べるだけにし、書くのは今までどおりチャットの `board-decide` で行う

## 背景

ADR 0017 で画面・サーバ・`status --html` のダッシュボードを外し、ボードを見る入口は `ai-board status` だけになった。
人向けの数行（`status-cli.ts`）には、GitHub の接続・ループの最後の手・判断待ち・AI 作業中・次の一手は出るが、アイデアの一覧は出ない。
ボードはスマホから Claude Code のクラウドのセッションで回すことが多く、ターミナルの数行よりも、3 つの区画を一目で見渡せるページで見たい。

2026-11-07 に案を比べた。

- **採る: 普通の Artifact のページに、`status --json --active` を埋め込む。** 区画とステージは CLI が決め、ページは描くだけ。コネクタが要らず、スマホで確実に開ける。中身は約 11KB で埋め込める
- **退けた: Artifact の DB にデータを置く。** 人の答え（2026-11-07）で使わない
- **退けた: 見る人の GitHub コネクタで、開くたびにデータ用ブランチを読む。** ステージの導出をページに複製することになり（ADR 0015 で退けた形）、外した更新ボタンと同じく、端末によってはページからコネクタを読み込めない
- **退けた: Artifact の Dashboard の型。** 数字とグラフを出どころ付きで見せる型で、カード一覧のボードには重い。数字の振り返り（`retro-artifact`）で使うのがよい
- **退けた: 人向けの `status` にアイデアの一覧を足すだけ。** スマホで見渡したい動機に届かない

## 論点

- **ひな形の置き場所。** 新しいスキル（例: `.claude/skills/board-view/`）にするか、`board-loop` の「ボードを見せて」の節に足すか。ADR 0017 の「`status --html` と `board-dashboard` のスキルを外す」と、HTML を本体（`src/`）で作らないこととの関係を ADR にどう書くか
- **流し込み方。** 決まったスクリプト（node の数行）でひな形の印を JSON に置き換える。カードのタイトルに `</script>` などが入っても崩れないよう、`<` を逃がして埋め込む。ページは値を `textContent` で出す
- **同じ URL への出し直し。** Artifact は同じファイルの道筋で出し直すと同じ URL になる。出す先のファイルをスクラッチパッドのどこに置くか、セッションをまたいで URL をどう覚えるか（覚えなければ新しい URL になる）
- **GitHub に届かないとき。** `status` は届かなければマージ済みの控えで描き、`forge` に理由が出る。ページにも接続の状態を出す
- **ページに出す項目。** 判断待ちは理由と出せる判断、AI 作業中は「止まっているか」「しばらく動きなし」、アイデアは区切り線の上下。PR の URL は押せるリンクにする

- 人と決めた（2026-11-07）: Artifact の DB は使わない。手元のデータ用ブランチを読み、PR の状態は `status` と同じく `gh` で引いてよい。出し先は Artifact の公開
- 外す前の形は、コミット 981587f の親にある（`src/board/cli/status-html.ts`、`.claude/skills/board-dashboard/SKILL.md`、消した ADR 0015）。更新ボタンの仕組みは `board-artifact-dashboard`（PR #71）

- ループの手ごとに出し直すのは `board-artifact-loop-republish`。このカードでは扱わない
