## アイデア

ループが 1 手を終えるたびに、ボードの Artifact（`board-artifact-view`）を同じ URL へ出し直す。開けばいつも最新のボードが見え、「ボードを見せて」と頼み直さずに済む。

- **出し直すのはループの手の終わりだけ。** 手を終えて `ai-board loop finish` を書いた後、このセッションでボードのページが公開済みなら同じ URL へ出し直す。公開していなければ何もしない
- **人の判断の後も出し直す。** `board-decide` で判断を書いた後も、カードの区画が変わるので出し直す
- **ページにボタンや状態は持たせない。** ページから Claude に頼む入口は作らない

## 背景

`board-artifact-view` のページは、頼んだ時点の写しで、ひとりでには新しくならない。
ADR 0017 には、判断待ちに気付くのは「ループが手の終わりにチャットで伝えるか、人が `status` を見たとき」とある。
ボードはスマホから Claude Code のクラウドのセッションで回すことが多く、カードが動くたびに頼み直すのは手間がかかる。
ボードが変わるのはほとんどがループの手の終わりと人の判断の直後なので、そこで出し直せば、開いたままの画面に近い使い方ができる。

## 論点

- **どこに書くか。** ループの手順（`.claude/skills/board-loop/SKILL.md` の手の終わり）と `board-decide` の手順（手順 5）に「公開済みなら出し直す」を足す。`board-artifact-view` がスキルでページを組むなら、そのスキルを呼ぶ形にする
- **URL をどこに覚えるか。** セッションの中だけか、セッションをまたぐか。Artifact は同じファイルのパスで出し直すと同じ URL になる
- **失敗しても手は止めない。** 出し直しは見るためのもので、ループの記録と同じく止まらないことを優先する（ADR 0014 の考え方）
- **承認。** 出し直すたびに Artifact の公開に承認が要るなら、ループの許可ルール（ADR 0012、`.claude/settings.json`）に足すか
