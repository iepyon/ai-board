## アイデア

カードが判断待ちに入ったときに、スマホへプッシュ通知を送る。

- **送るとき。** ループが手を終えて、カードが判断待ちの区画に入ったとき（計画の提出・PR の Ready・保留）。判断待ちが無くなったときや、AI の手が進んだだけのときは送らない
- **中身。** カードのタイトル、何の判断か（計画レビュー・PR レビュー・保留）、出せる判断を 1 行で書く。ボードの Artifact が公開済みなら、その URL も添える
- **送るのはループの手番の中だけ。** 常駐するものは作らない

## 背景

ADR 0017 で常に開いておく画面が無くなり、判断待ちに気付くのは、ループが手の終わりにチャットで伝えるか、人が `status` を見たときだけになった。
ループは人のいない間も `/loop` の間隔運転で回るので、手の終わりにチャットで伝えても、人がチャットを開くまで気付かない。
2026-11-06 の時点で、計画レビューと PR中 の時間の中央値は 6〜7 分と短いが、PR中 の合計 164h のうち 142h は 1 枚（`loop-fresh-context`）で、気付かれずに待った時間が長く残ることがある。
判断待ちに入った時点で知らせれば、人を待つ時間の長い外れ値を減らせる。

## 探索メモ

- Claude Code には、セッションからプッシュ通知を送る `PushNotification` のツールがある。クラウドのセッションから送れるか、スマホの Claude Code のアプリに届くかを計画で確かめる
- 1 周の中で判断待ちが複数できたときは 1 回にまとめるか
- ループが止まっているときは通知も届かない。これはこのカードでは扱わない
- `board-artifact-loop-republish` と組むと、通知から最新のボードへ飛べる
