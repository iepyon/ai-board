## アイデア

「ボードを見せて」で出すページ（`board-view`）のアイデアの区画を、判断待ち・AI 作業中と同じ白抜きのカードの見た目にそろえる。

- **見た目をそろえる。** アイデアの 1 行を、判断待ちと同じ `.card`（`--panel` の地・`--line` の枠・角丸）の箱にする。今の「番号つきの行と下線」の並びをやめる
- **並び順は残す。** rank の順の番号は、カードの中か脇に残す。区切り線（ここから下はあとで考える）も今までどおり描き、線より下のカードは薄く見せて区別する
- **中身は変えない。** タイトルと ID だけを載せる。ステージの札や判断の札はアイデアに付けない（アイデアは判断を待っていない）
- **直すのはひな形だけ。** `.claude/skills/board-view/template.html` の CSS と描画の JS を直す。`render.mjs` が流し込むデータの形と、`status --json --active` は変えない
- **テスト。** 区切り線の上と下の描き分けが崩れていないことを、`src/__tests__/board-view-render.test.ts` で確かめる

## 背景

2026-11-11、PR #103 のブランチで「ボードを見せて」のページを動かして確かめた。
判断待ちと AI 作業中はカードが白抜きの箱で並ぶのに対し、アイデアは番号つきの行が下線で区切られているだけで、同じページの中で見た目がそろっていなかった。
アイデアはボードの中でいちばん枚数が多い区画なので、1 枚ずつが箱になっていたほうが、ほかの区画と同じ感覚で目で追える。
このページは PR #103 で入るので、このカードはそのマージの後に進める。

## 論点

- **2 列の幅。** アイデアの列は今、画面の 2/5 の幅である。箱にすると枠の分だけ文字の幅が狭まるので、列の幅の比を変えるか
- **区切り線より下の見せ方。** 薄く見せるだけにするか、折りたたむか
