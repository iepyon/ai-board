## アイデア

振り返りの集計を、本体の純関数として戻し、`ai-board report --json`（名前は計画で決める）で JSON だけを出す。HTML やグラフは出さない。

- **集計を純関数にする。** 工程ごとの中央値とボトルネック、AI の区間の待ちと作業、差し戻しの率、長くかかったカードの上位を、期間を受け取って返す。テストで数字を固定する
- **消したものを取り出す。** コミット 981587f の親の `src/shared/board-metrics.ts`（`computeBoardMetrics` など）とそのテストを元にする
- **見せ方は外に置く。** `retro-artifact` のスキルは、自分で集計せずにこの JSON を描くだけにする

## 背景

`retro-artifact` のスキルが毎回 Claude に集計させると、同じデータでも数字や丸め方が頼むたびにぶれ、期間をまたいで比べられない。
中央値の取り方や、マージの時刻が無いカードの扱い（以前に直した、集計が伸び続ける件）のように、集計には間違えやすいところがあり、テストで守りたい。
ADR 0017 は、画面のために本体が考えることを減らすためにダッシュボードを外した。HTML・グラフ・更新ボタンを持たず、JSON の集計だけを戻すなら、外した理由とはぶつからないと考える。

## 探索メモ

- `retro-artifact` を使ってみて、数字のぶれが困るようになってから着手するのでもよい
- ADR 0017 の「集計・ログ・グラフ・更新ボタンのページを消す」の書き直しが要る。集計だけを戻す理由を ADR に書く
- `status --json` に足すか、別のサブコマンドにするかは計画で決める。`status` はループが毎周読むので、重い集計を載せると毎周の出力が大きくなる
