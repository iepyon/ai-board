【手順】
1. ブランチ skip-verify-scope で `npm run build`
2. スクラッチの bare リポジトリを origin にした clone を `AI_BOARD_DATA` で指し、`node dist/cli.js migrate --empty` で空のデータ用ブランチを作る
3. `AI_BOARD_DATA` を指したまま `node dist/cli.js card create` でダミーのカードを数枚作り、`node dist/cli.js --port <空きポート>`（または `npm run dev` と `npm run dev:web`）で起動する
4. ブラウザで詳細パネルを開き、ゲートの欄を見る
   - アイデア・計画提案中のカード: 「計画レビューを飛ばす」「動作確認を飛ばす」の両方が出る
   - 計画を承認して実装中にしたカード: 両方が出る
   - `card submit <id> --gate verify` で動作確認にしたカード: 「動作確認を飛ばす」の説明文が「印を入れると、提出済みのこのカードは動作確認を通ったものとみなされ、実装中へ戻って AI が PR を Ready にします。」に変わり、印を入れると実装中へ落ちる
   - 中止したカード: 「動作確認を飛ばす」が出ず、「計画レビューを飛ばす」だけが出る
5. PR中・マージ済みのカードは、本物のボードでマージ済みのカードの詳細パネルを開いて見るだけで確かめられる（書き込みは起きない）
