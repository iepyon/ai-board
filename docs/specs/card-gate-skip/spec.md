# card-gate-skip Specification

## Purpose

人が事前に「このカードのこのゲートは見ない」と決めた宣言を扱う。
宣言したゲートはレビューログを見ずに通過済みとする。

## Requirements

### Requirement: ゲートの事前スキップ

システムは カードに事前に宣言されたゲートを、レビューログを見ずに通過済みとして
扱わなければならない (MUST)。宣言できるのは人だけとする (MUST)。

宣言できるのは規定のゲート（`plan` / `verify`）だけとする。規定外のゲート名の宣言は受け付けては SHALL NOT。

人が verify ゲートを飛ばす宣言を出し入れする手段を、画面に提供しなければならない (MUST)。
宣言を書き換えるとき、他のゲートの宣言を変えては SHALL NOT。
AI エージェントが使う CLI に、宣言を書く手段を設けては SHALL NOT。

#### Scenario: 計画レビューを飛ばす

- **WHEN** カードが plan ゲートをスキップすると宣言している
- **THEN** 計画ファイルの有無やレビュー記録によらず plan ゲートは通過済みになる

#### Scenario: スキップしたカードは待ちの列に滞留しない

- **WHEN** 着手済みのカードが plan ゲートをスキップすると宣言し、計画ファイルが存在する
- **THEN** そのカードは `plan-review` に留まらない

#### Scenario: 動作確認を飛ばす

- **WHEN** 計画が承認済みのカードが verify ゲートをスキップすると宣言している
- **THEN** verify の提出の記録があっても verify ゲートは通過済みになり、そのカードは `verifying` に留まらない

#### Scenario: 動作確認を飛ばす宣言を外しても他のゲートは保たれる

- **WHEN** plan と verify の両方をスキップすると宣言したカードで、画面から verify の宣言を外す
- **THEN** スキップの宣言は plan だけになる

#### Scenario: 廃止されたゲートは宣言できない

- **WHEN** API でスキップ宣言に `explore` を含めて更新しようとする
- **THEN** 400 が返り、カードは変更されない

#### Scenario: 廃止されたゲートの宣言が DB に残っている

- **WHEN** DB にあるカードのスキップ宣言に `explore` が含まれている
- **THEN** そのカードは規定外の値として警告され、読み飛ばされる。ほかのカードの読み取りは続き、ボード全体は失敗しない
