# board-manual-start Specification

## Purpose

人がカードの列を手で動かせる範囲を決める。人が動かせるのは着手の指示（`startedAt`）だけで、
AI の成果物と人のレビュー記録が課す下限より手前へは戻せない。

## Requirements

### Requirement: 人が動かせるのはアイデアと計画提案中の間だけ

システムは 人が手で動かせる遷移を `idea` と `planning` の間に限定しなければならない (MUST)。
この遷移は着手時刻の記録と取り消しであり、画面は「着手」「着手を戻す」のボタンとして出す。
列をまたいでカードをドラッグする手段は設けては SHALL NOT。ほかの列はどれも実態から立つので、
カードを置いても着地できないからである。

さらにシステムは AI の成果物と人のレビュー記録が課す下限より手前の列へ戻すボタンを
出しては SHALL NOT。下限は、着手時刻を外したカードに同じ導出を適用した結果とする。
ボードは各カードに、下限と、その下限のもとで手で入れられる列を返す。画面はその列にだけボタンを出す。

API は着手時刻の取り消しそのものを拒まない。取り消しても導出の結果は下限より手前には落ちない。

#### Scenario: まだ何も成果物が無い

- **WHEN** カードにレビュー記録も計画ファイルも PR も無い
- **THEN** `idea` と `planning` の両方へ手で動かせる（着手していなければ「着手」、していれば「着手を戻す」が出る）

#### Scenario: 計画が出ている

- **WHEN** カードの計画ファイルが存在し、plan ゲートが未提出か判断待ちである
- **THEN** 下限は `plan-review` となり、手で動かせる先は 1 つも無い

#### Scenario: Draft の PR が出ている

- **WHEN** カードに open で Draft の PR が紐付き、レビュー記録が無い
- **THEN** 下限は `plan-review` となり、手で動かせる先は 1 つも無い

#### Scenario: PR が Ready になっている

- **WHEN** カードに open で Draft でない PR が紐付いている
- **THEN** 下限は `pr` となり、手で動かせる先は 1 つも無い

#### Scenario: 下限より手前へ API で戻そうとする

- **WHEN** 計画ファイルがあり plan ゲートが判断待ちの着手済みのカードに、API で着手時刻の取り消しを送る
- **THEN** 着手時刻は消えるが、ステージは `plan-review` のままである
