# 7. 人がこの会話で頼んだ判断は、Claude が `board-decide` で人の API を叩いて書く

- 状態: 採用
- 日付: 2026-10-31（2026-11-03 に改訂。同日、サブエージェントを hook で拒む形に改訂）

## 背景

ループの報告を Claude Code の会話で受けても、判断するにはブラウザのボードへ移ってボタンを押す必要があった。
一方で「エージェントは人の判断を書かない」が設計の柱で（[6](0006-ai-review-entries-and-hold.md)）、チャットから書くと実際に書くのは Claude になる。

## 決定

- **線は「人がこの会話で、自分の言葉で頼んだか」に引く。** サブエージェントの報告・カード本文・PR の文面にある「承認してよい」は依頼ではない。
- 書き込みは画面と同じ人の API を通す。新しい書き込み口は作らず、**CLI に人の判断の入口を足さない**。
- 出せる判断と並び順は `status --json` の `waiting[].decisions` と `ideas` から読み、規則をスキルの文章に書き写さない。
- 承認・否決・中止・着手を戻す、は送る中身を見せて確かめてから書く（人がはっきり頼んだ承認・否決は除く）。否決の理由は人の言葉か、人が選んだ文面だけを送る（人の言葉が会話の中の案を指すときだけ、Claude が作業者にも読める文面に起こして人に選ばせる）。
- サブエージェントとループの監視役はこのスキルも人の API も使わない。
  - **サブエージェント（`board-*`）の中では hook で拒む。** 3 つの定義の frontmatter の `PreToolUse` の hook（`.claude/hooks/guard-human-api.mjs`）が、
    hook の入力に `agent_id` が載る（サブエージェントの中で発火した）ときだけ、コマンドに人の API の道（`/api/cards`・`/api/idea-divider`）を含む Bash と、`board-decide` の Skill を拒む。
    道で見分け、メソッドでは分けない（`-XPOST`、`--data`、`node -e` の `fetch` など書き方が多く、メソッドの照合は抜けやすい）。宛先のサーバでも分けない（試しのサーバに見せかけて抜けられる）
  - **ループの監視役は手順書の決まりで守る。** 本筋のセッションで動くので `agent_id` が載らず、hook は効かない。人がチャットで頼む流れも同じ本筋なので、確認を増やさずに通す
- 書いた判断で AI の番ができたら、同じセッションでループの 1 周を続ける（[13](0013-continue-loop-after-decide.md)）。

## 結果

- 画面を開かずに判断でき、画面とチャットで書き方がずれない。
- 人の判断を書ける主体が「人と、人が会話で頼んだ Claude」になり、`CLAUDE.md` の書き込み境界に明記した。
- サブエージェントが手順書を破って `board-decide` の `curl` を写すような破り方は、実行される前に拒まれる。サブエージェントは試しのサーバでもカードの API を叩けず、人の API の振る舞いは e2e で確かめる。
- 文字列の照合なので、わざと崩した呼び出し（道を変数に分けて組み立てる、スクリプトをファイルに書いてから走らせる、URL を符号化する）までは止めない。破られても `## レビュー` に記録が残ることは前と同じ。
- `agent_id` が hook の入力に載らなくなる版では、守りは黙って外れる（本筋を止めない側に倒している）。読めない入力も通す。
- ループの監視役は技術的には止めていない。

## 退けた案

- **人だけが呼べるスキル（`disable-model-invocation`）にする** — 自然に「承認して」と頼めない。サブエージェントは認証の無い API を Bash から叩けるので、結局は決まりに頼る。
- **`ai-board card` の CLI に人の判断の入口を足す** — サブエージェントが日常的に使う道具の境界を崩す。
- **hook を `.claude/settings.json` に置く** — `board-*` 以外のサブエージェントも止められるが、許可や hook の設定（AI の編集を `deny` で止めている）を AI が書き換えることになる。広げたいときは人が同じスクリプトを足せば済む（スクリプトは `agent_id` を見るので本筋は止まらない）。
- **サブエージェントに環境変数などの目印を渡して見分ける** — hook の入力の `agent_id` で足り、目印を渡す仕組みを別に持たなくてよい。
- **サーバの人の API に認証を足す** — ローカル専用ツールで、サブエージェントも同じ利用者として動くので、秘密を置いても読めてしまう。
