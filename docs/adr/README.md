# ADR（Architecture Decision Record）

ai-board の設計判断を、決めた時点の文脈・捨てた代案・その結果ごと 1 判断 1 ファイルで残す。
今どう作られているかは [`docs/architecture.md`](../architecture.md)、何を満たすかは [`docs/specs/`](../specs/) にある。
ここには**なぜそう決めたか**を書く。不変条件を外したくなったら、まず該当する ADR を読む。

書き方と、新しい判断の足し方・置き換え方は [`.claude/skills/adr/SKILL.md`](../../.claude/skills/adr/SKILL.md)（`adr` のスキル）にある。
ひな形は [`.claude/skills/adr/template.md`](../../.claude/skills/adr/template.md)。
0001〜0024 は 2026-11-02 に git log・計画の archive・仕様から書き起こした。
