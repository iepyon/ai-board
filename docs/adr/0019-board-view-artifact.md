# 19. ボードを見るページは、スキルのひな形に `status --json --active` を流し込んで Artifact で出す

- 状態: 採用
- 日付: 2026-11-07

## 背景

ADR [17](0017-remove-web-and-server.md) で画面・サーバ・`status --html` のダッシュボードを外し、ボードを見る入口は `ai-board status` の数行だけになった。
数行にはアイデアの一覧が出ず、スマホから Claude Code のクラウドのセッションで回すときに、3 つの区画を一目で見渡せなかった。
外したダッシュボードは集計・ログ・グラフ・更新ボタンまで抱え、更新ボタンはページからコネクタを読み込めない端末で動かなかった。

## 決定

- **ページは `board-view` のスキル（`.claude/skills/board-view/`）が組む。本体（`src/`）では HTML を作らない。** ひな形の `template.html` に、`render.mjs` が `status --json --active` を流し込む。
- **ページは描くだけで、区画・並び・ステージを導出しない。** 文言とステージの名前は、人向けの `status` と同じ本体の関数（`status-describe.ts`・`stage-labels.ts`）で作ってから埋め込む。
- **データはページに埋め込み、`capabilities` を宣言しない。** Artifact の DB・コネクタ・ページ自身の保存を使わない。PR の状態は `status` と同じく `gh` で引く。
- **頼まれたときだけ出す。** 「ボードを見せて」で公開し、同じセッションではスクラッチパッドの同じファイルから同じ URL に出し直す。ページから判断は書けない。
- 埋め込む JSON は `<` と U+2028 / U+2029 を逃がし、ページは `textContent` で描く。カードの文字列は信頼しない。

## 結果

- スマホで判断待ち・AI 作業中・アイデアを 1 枚で見渡せる。見た目はひな形で決まり、頼むたびにぶれない。
- ページは頼んだ時点の写しで、開いたままでは新しくならない（ループの手ごとの出し直しは別のカード）。新しいセッションでは新しい URL になる。
- `render.mjs` は `dist/` の関数に頼るので、スキルの手順で `dist-check` を通してから走らせる。テストは `src/` の関数を渡して純関数だけを確かめる。

## 退けた案

- **本体の CLI で HTML を出す（`status --html` を戻す）** — ADR 17 で外した表示の話を本体に戻すことになる。
- **Artifact の DB にデータを置く・見る人の GitHub コネクタで読む** — 人が DB を使わないと決めた。コネクタは端末によってページから読み込めない。
- **Artifact の Dashboard の型** — 数字とグラフを出どころ付きで見せる型で、カード一覧には重い。
- **Claude がその場で HTML を書く・ひな形に文言の表を写す** — 見た目がぶれる / 本体と食い違っても気づけない。
